02

Real screening criteria

Generate 10 miniproteins, validate sequences and structure files, then rank using actual model confidence. Inspect up to 3 candidates.

Pass gates: binding confidence ≥ 0.70 and structure confidence ≥ 0.68.

Selectivity, toxicity, immunogenicity, expression yield and binding kinetics: not evaluated. No invented scores are assigned.

If none pass, the strongest available predictions are labelled diagnostic only.
